## File Overview

### ← index.html

HTML files are for content! Add your text, images, buttons, and more using HTML tags.

### ← style.css

CSS files add styling rules to the content like changing colors and fonts. 

### ← script.js

JavaScript files add interactivity to the website using code. This is where you can listen for events, then take an action.

### ← assets

Drag in `assets`, like images or music, to add them to the project.
